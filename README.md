# How to use this thing

Just go to [https://www.andrewt.net/dithered-qr-codes](https://www.andrewt.net/dithered-qr-codes)

but if you really want to run it yourself:

## Clone the repo

```sh
ssh://git@codeberg.org/andrew-t/dithered-qr-codes.git
cd dithered-qr-codes
```

## Install the QR code library

```sh
yarn
```

you might need install yarn and/or node first. `npm install` ought to work too

## Start hosting

```sh
python -m http.server
```

or whatever
